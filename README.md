# ClipShot

**Буфер обмена и скриншоты для Windows 11.**

ClipShot хранит скопированный текст и картинки, помогает быстро вставлять шаблоны и делает снимки выделенной области. Интерфейс на русском языке. Текущая версия: **0.6.1**.

## Возможности

- **Alt+F1** — история рядом с курсором, поиск сразу готов к вводу. Выбор мышью или стрелками, Enter копирует, Esc закрывает.
- **Alt+F2** — снимок выбранной области в буфер и историю. Esc отменяет. Оба сочетания настраиваются.
- История без дублей; повторное копирование поднимает запись наверх. Группы по дням сворачиваются.
- Шаблоны отдельным разделом: Ctrl+S добавляет выбранную запись, доступны изменение текста и порядок.
- Увеличенный предпросмотр текста и картинки при наведении.
- Семь тем: градиентная, прозрачная с акриловым фоном Windows, белая, чёрная, тёмная, Windows 98 и Windows XP.
- Хранение 30/90 дней или бессрочно. Очистка истории сохраняет шаблоны.
- Трей, автозапуск, обновление поверх старой версии без предварительного удаления.
- Кнопка «Справка» с коротким напутствием.
- Интерфейс по умолчанию русский. Необязательное переключение на английский запланировано в настройках.

Выбор клипа копирует его в буфер и сохраняет окно открытым; вставка выполняется привычным Ctrl+V. Крестик и сворачивание скрывают окно в трей. Автоматическую вставку в предыдущее приложение можно включить в настройках; она выполняется только при доступном текстовом курсоре. Поиск работает по тексту и названию, распознавания текста в картинках пока нет.

## Установка

Скачать версионный `ClipShot-Setup-<версия>.exe` из [Releases](https://github.com/gromit7/ClipShot/releases). Установка для текущего пользователя, без прав администратора. Если ClipNest/ClipShot уже работает, установщик запрашивает его штатное завершение и ждёт закрытия.

На ПК разработчика проверенные пакеты сохраняются прямо в `D:/install/Codex Software/`, без подпапок. В имени всегда есть версия.

## Данные

История и настройки хранятся локально. Программа не отправляет буфер на сервер; синхронизация не реализована. Для обновления прежнего ClipNest сохранены внутренние ключи и папка `%LOCALAPPDATA%/ClipNest`. Данные пользователя не входят в исходники и установщик.

История буфера может содержать личную информацию. Шифрование, исключения приложений и пауза записи пока не реализованы. Цифровая подпись установщика пока отсутствует.

## Сборка

C#, .NET 10, WinUI 3, SQLite. Нужна Windows x64 и PowerShell 7.

```powershell
./scripts/Setup.ps1
./scripts/Build.ps1 -Test -Publish
./ClipShot-app/ClipShot.exe
```

Setup устанавливает локальный .NET SDK, если подходящего нет, и восстанавливает пакеты. Он не меняет аккаунт GitHub или настройки Git. Для установщика нужен NSIS 3.

```powershell
./scripts/Test-Release.ps1 -MakeNsis 'C:/path/to/makensis.exe' -PublishInstaller
```

## Новое в 0.6.0

- Разметка сохранённого снимка: карандаш в строке → протянуть стрелку → Enter. Стрелки выравниваются вблизи горизонтали, вертикали и диагоналей; Shift принудительно выравнивает. Есть рамка, подпись, мозаика, непрозрачное скрытие, отмена/повтор и сохранение PNG. Оригинал остаётся в истории. Для секретов используйте «Скрыть область».
- Микрофон: цвет основного значка ClipShot показывает состояние; отдельной иконки микрофона нет. Левое нажатие открывает историю, переключение микрофона доступно в меню правой кнопки. Ctrl+Alt+M по умолчанию; в настройках доступны Ctrl+Alt+F3 и отключение сочетания. Боковая кнопка мыши назначается по желанию. MX Vertical также можно настроить на Ctrl+Alt+M через Logi Options+.
- Выбор основного, всех подключённых или выбранных микрофонов. Если часть включена, переключение выключает выбранные; следующее нажатие включает все выбранные. Статус перечитывается каждые 750 мс, включая изменения другими программами.
- Зелёный фон значка ClipShot — звук включён в Windows, красный — выключен, жёлтый — смешанное состояние, серый — недоступен. Плашка не перехватывает фокус. Это статус отключения звука, а не индикатор записи приложением. Аппаратные выключатели, не сообщающие статус Windows, отдельно не определяются. Видимость значка вне скрытой области трея настраивается в Windows.
- Русский по умолчанию, English ненавязчиво внизу настроек. Семь тем сохранены. Справка: «Я верю в тебя, ты разберёшься сам.»

Для дополнительных кнопок, не передающих стандартные X1/X2, назначьте сочетание через ПО производителя. Можно запускать `ClipShot.exe --toggle-microphone`: команда передаётся существующему экземпляру.

## Новое в 0.6.1

Один значок ClipShot в трее: зелёный фон при включённом микрофоне, красно-розовый при выключенном, жёлтый при смешанном статусе, серый при недоступном. Белый рисунок буфера остаётся узнаваемым. Если управление микрофоном отключено, возвращается исходный синий значок.

Плашка переключения в стиле комикс + киберпанк: рубленая рамка и хвост реплики, неоновые акценты, точечная фактура, крупный статус. Появляется на 1,9 секунды без перехвата фокуса; при повторном нажатии заменяется свежим статусом.
