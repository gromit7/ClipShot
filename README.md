# ClipShot

**Буфер обмена и скриншоты для Windows 10/11 x64.**

ClipShot хранит скопированный текст и картинки, помогает быстро вставлять шаблоны и делает снимки выделенной области. Интерфейс на русском языке. Текущая опубликованная версия: **0.7.7**.

## Открытый исходный код

Код открыт по [лицензии MIT](LICENSE), есть [пояснение на русском](LICENSE.ru.md). Вы можете изучать, изменять и собирать программу самостоятельно. Для каждого выпуска публикуются тег исходников, сведения о сборке, SHA-256 установщика и результаты проверок. [Как проверить происхождение выпуска](docs/SOURCE-VERIFICATION.md). Публичные [сборки и тесты GitHub Actions](https://github.com/gromit7/ClipShot/actions) содержат отчёты и независимо собранный пакет приложения.

## Возможности

- **Alt+F1** — история рядом с курсором, поиск открывается по нажатию лупы. Выбор мышью или стрелками, Enter копирует, Esc скрывает. Правый клик на пустом месте открывает настройки и справку.
- **Alt+F2** или **Shift+PrintScreen** — снимок выбранной области в буфер и историю. Esc отменяет. Оба сочетания настраиваются.
- **Ctrl+Alt+M** — переключение микрофона; можно назначить боковую кнопку мыши. Один основной значок в трее показывает состояние.
- Карандаш у снимка — стрелки, рамки, подписи и скрытие области. Enter применяет правки к тому же клипу и буферу; отдельный экспорт — PNG/JPEG.
- История без дублей; повторное копирование поднимает запись наверх. Непустые группы раскрываются нажатием на заголовок и сворачиваются повторным нажатием, сбоку в сторону свободного места; в настройках доступен обычный список. Наведение не меняет раздел и высоту окна, не выбирает и не копирует клип.
- Компактная панель: даты сверху, шаблоны снизу, поиск под лупой. Щелчок вне программы плавно скрывает окно; значок трея или Alt+F1 возвращает его.
- «Всегда поверх окон» в контексте окна и трея; выбор сохраняется, Esc и ручное скрытие работают.
- Шаблоны отдельным разделом: Ctrl+S добавляет выбранную запись, доступны изменение текста и порядок.
- Увеличенный предпросмотр текста и картинки при наведении.
- Восемь тем: градиентная, прозрачная с акриловым фоном Windows, белая, чёрная, тёмная, Windows 98, Windows XP и розовая с чёрным и рыжим котиками.
- Хранение 30/90 дней или бессрочно. Очистка истории сохраняет шаблоны.
- Трей, автозапуск, автоматические обновления с VDS во время простоя и аварийный откат; сохранение данных. Переход с 0.7.0 на 0.7.1 — её прежней кнопкой обновления; далее автоматически.
- Справка: короткий список всех возможностей и действующих сочетаний. Проверка обновлений при запуске и один раз в день во время простоя, один короткий запрос.
- Интерфейс по умолчанию русский. Необязательное переключение на английский доступно внизу настроек.

Выбор клипа копирует его в буфер и сохраняет окно открытым; вставка выполняется привычным Ctrl+V. Верхней панели нет. Меню трея и тихая ссылка внизу содержат проверку обновления. Версия доступна в подсказке значка трея. Готовая кнопка «Обновить сейчас» мягко пульсирует; нажатие даёт явный отклик и закрывает настройки. Фоновая установка и ручной запуск доступны одновременно, без переключателя режимов. Скачанный пакет сохраняется до следующего запуска; загрузка восстанавливается после обрыва связи. Проверка выполняется при запуске и один раз в день во время простоя. Ручная кнопка проверяет, скачивает и устанавливает обновление. Сообщение «Обновлений нет» содержит текущую версию, сообщение о новом выпуске и готовая кнопка — номер новой версии. После установки появляется короткая плашка с новыми возможностями. Значок трея скрывает и показывает окно; перетаскивание за пустую область двигает его. Автоматическую вставку в предыдущее приложение можно включить в настройках; она выполняется только при доступном текстовом курсоре. Поиск работает по тексту и названию, распознавания текста в картинках пока нет.

## Новое в 0.7.7

- [Импорт Clipdiary](docs/CLIPDIARY-IMPORT.md): история с исходными датами и шаблоны, без дублей, с отменой; исходные базы не меняются. Нужна дополнительная независимая проверка совместимости на данных, созданных самой Clipdiary в изолированной VM.
- Раскрытие внутри списка меняет высоту панели и закрепляет её справа на основном мониторе. Раскрытие вбок остаётся возле курсора.
- Плашка после обновления показывает краткие изменения пяти последних выпусков и остаётся до нажатия на неё; длинный список можно прокрутить.

Эти изменения входят в установщики 0.7.7.
## Установка

Выбрать `ClipShot-Win10-Setup-<версия>.exe` или `ClipShot-Win11-Setup-<версия>.exe` из [Releases](https://github.com/gromit7/ClipShot/releases) или [свежий архив российского зеркала](https://bot.data-clouds.ru/clipshot/ClipShot-Latest.zip). [Как проверяется и публикуется зеркало](docs/MIRROR.md). Установка для текущего пользователя, без прав администратора. Если ClipNest/ClipShot уже работает, установщик запрашивает его штатное завершение и ждёт закрытия.

На ПК разработчика проверенные пакеты сохраняются прямо в `D:/install/Codex Software/`, без подпапок. В имени всегда есть версия.

## Данные

История и настройки хранятся локально. Программа не отправляет буфер на сервер; синхронизация не реализована. Для обновления прежнего ClipNest сохранены внутренние ключи и папка `%LOCALAPPDATA%/ClipNest`. Данные пользователя не входят в исходники и установщик.

История буфера может содержать личную информацию. Шифрование, исключения приложений и пауза записи пока не реализованы. Цифровая подпись установщика пока отсутствует.

## Сборка

C#, .NET 10, WinUI 3, SQLite. Нужна Windows x64 и PowerShell 7.

```powershell
./scripts/Setup.ps1
./scripts/Build.ps1 -Test -Publish
./ClipShot-app/ClipShot.exe
```

Setup устанавливает локальный .NET SDK, если подходящего нет, и восстанавливает пакеты. Он не меняет аккаунт GitHub или настройки Git. Для установщика нужен NSIS 3.

```powershell
./scripts/Release.ps1 -MakeNsis 'C:/path/to/makensis.exe' -NotesFile 'C:/path/to/release-notes.md'
```

## Новое в 0.6.0

- Разметка сохранённого снимка: карандаш в строке → протянуть стрелку → Enter. Стрелки выравниваются вблизи горизонтали, вертикали и диагоналей; Shift принудительно выравнивает. Есть рамка, подпись, мозаика, непрозрачное скрытие, отмена/повтор и сохранение PNG. Оригинал остаётся в истории. Для секретов используйте «Скрыть область».
- Микрофон: основной значок ClipShot показывает состояние; отдельной иконки микрофона нет. Левое нажатие открывает историю, переключение микрофона доступно в меню правой кнопки. Ctrl+Alt+M по умолчанию; в настройках доступны Ctrl+Alt+F3 и отключение сочетания. Боковая кнопка мыши назначается по желанию. MX Vertical также можно настроить на Ctrl+Alt+M через Logi Options+.
- Выбор основного, всех подключённых или выбранных микрофонов. Если часть включена, переключение выключает выбранные; следующее нажатие включает все выбранные. Статус перечитывается каждые 750 мс, включая изменения другими программами.
- Синий значок с микрофоном — звук включён в Windows, перечёркнутый — выключен, жёлтая отметка — смешанное состояние, серый — недоступен. Плашка не перехватывает фокус. Это статус отключения звука, а не индикатор записи приложением. Аппаратные выключатели, не сообщающие статус Windows, отдельно не определяются. Видимость значка вне скрытой области трея настраивается в Windows.
- Русский по умолчанию, English ненавязчиво внизу настроек. Семь тем сохранены. Справка содержит краткий список возможностей.

Для дополнительных кнопок, не передающих стандартные X1/X2, назначьте сочетание через ПО производителя. Можно запускать `ClipShot.exe --toggle-microphone`: команда передаётся существующему экземпляру.

## Новое в 0.6.1

В 0.6.1 основной значок менял цвет вместо отдельной иконки микрофона. В 0.6.2 цветные варианты заменены предоставленной автором парой изображений; смешанное состояние отмечается жёлтым индикатором, недоступное — серым вариантом.

Плашка переключения в стиле комикс + киберпанк: рубленая рамка и хвост реплики, неоновые акценты, точечная фактура, крупный статус. Появляется на 1,9 секунды без перехвата фокуса; при повторном нажатии заменяется свежим статусом.

## Новое в 0.6.2

- Новые значки из предоставленной автором пары: синий с микрофоном для включённого состояния и перечёркнутый для выключенного. Одно место в трее, размеры ICO от 16 до 256 пикселей. Новая иконка также в окне, exe и установщике.
- Пустые разделы истории и шаблонов скрываются. Непустые заголовки отличаются спокойным фоном и более мелким полужирным текстом.
- Лицензия, инструкция независимой сборки и русские формы сообщений об ошибках/предложениях.

[Автоматическое обновление](docs/AUTOUPDATE-PLAN.md) спроектировано как следующий этап; в 0.6.2 оно ещё не включено.
