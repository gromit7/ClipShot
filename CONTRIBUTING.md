# Участие в разработке ClipShot

Обсуждения, сообщения об ошибках и описания изменений можно писать по-русски.

1. Укажите версию ClipShot и Windows, шаги воспроизведения, ожидаемое и фактическое поведение.
2. Не прикладывайте историю буфера, пароли, личные реквизиты и секретные снимки. Для примеров используйте вымышленные данные.
3. Сделайте ответвление репозитория и отдельную ветку. Перед изменениями прочитайте AGENTS.md.
4. На Windows 11 x64 с PowerShell 7 выполните scripts/Setup.ps1, затем scripts/Build.ps1 -Test -Publish.
5. Для изменений интерфейса проверьте синтетические режимы, описанные в docs/TESTING.md; обычную личную базу для тестов не используйте.
6. В запросе на слияние объясните проблему, изменение поведения и проведённые проверки.

Код проекта открыт по лицензии MIT. Отправляя свой вклад, вы предлагаете включить его в проект на этих условиях.
