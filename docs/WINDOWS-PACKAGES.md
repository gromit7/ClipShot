# Пакеты для Windows10 и Windows11

Выпуски с0.7.4 содержат два пользовательских установщика из одного общего набора EXE/DLL/ресурсов:

| Пакет | Сборки Windows | Назначение |
| --- | --- | --- |
| ClipShot-Win10-Setup-X.Y.Z.exe | 17763–21999 | Windows10x64, включая1809/LTSC2019 |
| ClipShot-Win11-Setup-X.Y.Z.exe | от22000 | Windows11x64 |
| ClipShot-Setup-X.Y.Z.exe | от17763 | Совместимое обновление старых клиентов, самостоятельное восстановление |

Версия всегда находится в имени файла. Папка приложения, база данных, шаблоны и настройки общие. Установка поверх предыдущего пакета сохраняет данные; параллельных установок и отдельных баз для двух ОС не создаётся.

## Выбор обновления

Клиенты0.7.0–0.7.3 продолжают читать legacy stable из schema1. Клиенты от0.7.4 выбирают variants.win10 или variants.win11 по фактической сборке ОС. Отсутствующее или отозванное предложение не заменяется чужим вариантом. Каждый пакет проходит проверку официального URL, размера и SHA-256, повторную проверку перед запуском и собственный OS guard установщика. Неподходящий ручной пакет отказывает до завершения работающей программы или замены файлов.

## Публикация

Release.ps1 проверяет три пакета GitHub и копирует всё семейство на зеркало до переключения ленты. SHA256SUMS и buildinfo перечисляют три файла и общий payload. На D:/install/Codex Software остаются только два пользовательских пакета текущей версии. Legacy хранится в GitHub, зеркале и локальном архиве для совместимости старых клиентов.

Постоянный ClipShot-Latest.zip содержит универсальный legacy EXE. Он нужен для одной независимой ссылки, пригодной обеим поддерживаемым ОС; прямые Win10/Win11-ссылки имеют версию в имени.

## Что проверено и что требует реальной машины

Модульные проверки покрывают выбор пакета, строгие имена/URL, pending cache, зеркало, отзыв и аварийный откат. Скриптовые фикстуры проверяют публикацию трёх пакетов, хеши, атомарность семейства и сохранение прежних файлов при ошибке. Три реально скомпилированных NSIS wrapper проверяются на граничных сборках17762/17763/19041/21999/22000/26100 в диагностическом режиме, который ничего не устанавливает.

На рабочемWindows11 дополнительно выполняются настоящий путь установки и обновления Win11-пакета на синтетических данных, проверка общего payload, сохранения базы и удаления. Фактический запуск наWindows10LTSC2019 — отдельная проверка на целевой машине. Пока такой результат не получен, его нельзя считать подтверждённым только по сборке или OS guard.

## Официальные требования платформы

Одинаковая корректность и набор функций на поддерживаемых Windows10/11 — требование проекта. Минимальная матрица фактического запуска: LTSC2019/build17763, обычная Windows10 22H2/build19045, Windows11/build22000 и текущая Windows11. Расширение матрицы: LTSC2021/build19044 и Windows11 LTSC2024/build26100. Для каждой машины фиксировать точную сборку, архитектуру, версию ClipShot и проверенные сценарии. Отдельно проверять настоящие горячие клавиши, мышь, буфер, несколько микрофонов и DPI100/150%; встроенные self-test не заменяют эти проверки. Поддержка Microsoft по жизненному циклу и фактическая совместимость приложения — разные утверждения. Windows10 до1809, x86 и ARM этой сборкой не заявлены.
