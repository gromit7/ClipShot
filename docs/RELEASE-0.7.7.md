# ClipShot 0.7.7

- Обновления загружаются с российского VDS напрямую или через германский релей с кешем: быстрый путь выбирается автоматически, докачка и проверка SHA-256 сохранены.
- Добавлен импорт истории и шаблонов Clipdiary с сохранением исходных дат, без дублей и с отменой. Предложение при запуске, ручная команда в меню.
- Раскрытие разделов внутри списка увеличивает высоту панели и закрепляет её справа на основном мониторе; ширина сохраняется, переполнение прокручивается.
- Плашка после установки или обновления показывает краткие изменения пяти последних выпусков; наведите мышь для чтения и прокрутки.
- Лента версий перенесена на российский VDS. Германский релей не кеширует её, поэтому отзыв версии и откат не задерживаются кешем.

Переходный выпуск: GitHub пока остаётся публичным для старых клиентов. Новые клиенты читают ленту VDS; закрытие репозитория будет выполнено после подтверждения обновления тестеров. VPN, маршруты и настройки сети программа не меняет.

Импорт не изменяет исходную базу. Неподдерживаемые или повреждённые записи учитываются как пропущенные. Декодер восстановлен статически и проверен искусственными payload/SQLite; независимая межпрограммная проверка на данных, созданных самой Clipdiary в изолированной VM, пока не выполнена. Личные базы в тестах не использовались.

Установка поверх прежней версии сохраняет историю, шаблоны и настройки. Windows 10 x64 от 1809/LTSC2019 и Windows 11 x64; реальный прогон LTSC пока не подтверждён.
