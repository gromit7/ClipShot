# Российское зеркало выпусков

Пакеты: https://bot.data-clouds.ru/clipshot/v<версия>/ClipShot-Setup-<версия>.exe.
Постоянный архив: https://bot.data-clouds.ru/clipshot/ClipShot-Latest.zip — внутри установщик с версией в имени.

Приложение получает ожидаемые размер и SHA-256 из GitHub. Небольшие параллельные пробы выбирают доступный быстрый источник пакета; ошибки ведут к повтору/другому источнику. VPN и маршруты не меняются. Если сам GitHub недоступен, этот выпуск пока не имеет независимой подписанной ленты метаданных.

## Публикация

Release.ps1 требует переменную CLIPSHOT_MIRROR_EXECUTOR: путь к приватному локальному PowerShell-исполнителю с параметром Command. Реквизиты SSH и секреты в исходники не входят. Исполнитель использует уже настроенный доступ через Gateway и обязан возвращать результат команды; GitHub-секретов на зеркало не передаётся.

Publish-Mirror.ps1 проверяет существующий стабильный выпуск GitHub, скачивает пакет на сервере и сверяет размер/SHA-256. Каталог версии неизменяем. ZIP проверяется по составу и SHA распакованного EXE. latest.json и ZIP переключаются общей ссылкой current после проверки. Предыдущие каталоги сохраняются для отката; их удаление — отдельная операция. Общая блокировка предотвращает одновременную публикацию.

Пример проверки: ./scripts/Publish-Mirror.ps1 -Version 0.7.3 -CheckOnly. Проверка не меняет публикацию. При штатном выпуске зеркало проверяется перед переключением общей ленты автообновления и копированием установщика в локальный каталог.

## Проверка и откат

Проверять внешний HTTPS, сертификат, HTTP Range и полный SHA-256. Успех на сервере не доказывает доступность из каждой пользовательской сети. Результат замера с одной сети не обещает такую же скорость с другой.

Для отката версии приложения используется отдельная update-policy.json и процесс публикации ленты. Откат nginx выполняется по приватной резервной конфигурации на VDS с nginx -t и graceful reload. Не менять SSH, VPN и firewall ради публикации пакетов.
