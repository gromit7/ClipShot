# ClipShot 0.7.13

## Что изменилось

- История изображений расходует меньше памяти: оригиналы загружаются по запросу, миниатюры и предпросмотр декодируются в уменьшенном размере.
- При скрытии и повторном открытии освобождаются прежние изображения и отменяются устаревшие загрузки.
- Значок трея стал простым ярким буфером обмена; состояние микрофона показывается небольшой отметкой.

- Обновления больше не возвращают на рабочий стол ярлык, который вы удалили. Это действует и при повторной установке поверх программы.
- Существующий ярлык обновляется как прежде; при первой установке он создаётся, если выбран в установщике.

История, шаблоны и настройки сохраняются. Запуск из меню Пуск и автоматический запуск после обновления не изменены.
