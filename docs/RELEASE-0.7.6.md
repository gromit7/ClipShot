# ClipShot 0.7.6

- Исправлен отказ автообновления, когда старый обновлятор удерживал папку приложения как рабочую: переход с 0.7.4 выполняется через совместимый обновлятор в нейтральной папке.
- Сохранены проверка SHA-256, целостности всех файлов, резервная копия и откат при ошибке.
- Ручная проверка разрешает повторить ранее неудачное обновление; фон не запускает неудачную версию по кругу.
- Добавлен технический журнал этапов обновления без истории буфера и личных данных.
- Проверки очищены от дублей и усилены для выбора зеркала, отмены загрузки, неполной установки и сохранности шаблонов.

Установка поверх прежней версии сохраняет историю, шаблоны и настройки. Windows 10 x64 от 1809/LTSC2019 и Windows 11 x64; реальный прогон LTSC пока не подтверждён.
