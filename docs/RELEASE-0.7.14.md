# ClipShot 0.7.14

## Что изменилось

- Окно выделения скриншота больше не имеет системной рамки: края и углы доступны для начала и завершения выделения.
- После успешного снимка звучит короткий механический затвор. В настройках звук можно прослушать и отключить.
- Тема переключается без перезапуска из контекстного меню окна и значка трея; текущая тема отмечена.
- Исправлена читаемость заголовков, значков, счётчиков и элементов управления во всех темах. Windows 98 получила квадратные рельефные элементы, Windows XP — светлые объёмные кнопки с синими границами.
- Добавлены темы «Светлая бежевая», «Тёмная синяя» и «Светлая зелёная»; названия остальных тем уточнены.
- Уведомления получили спокойное оформление со значком буфера обмена. Успешная проверка без новой версии показывает «Обновлений нет»; ошибка связи отображается отдельно.

История, изображения, шаблоны и настройки сохраняются при обновлении.
