# ClipShot 0.7.10

## Что изменилось

- «Сегодня», «Вчера», «Шаблоны» и другие разделы раскрываются и сворачиваются нажатием на заголовок. Наведение больше не открывает и не закрывает списки, поэтому панель не скачет при движении мыши.
- Управление разделами клавиатурой и увеличенный просмотр отдельного клипа при наведении сохранены.

Исправления курсора выделения и перемещения окна проходят проверку; до завершения выпуска этот файл не является подтверждением публикации.

Установка поверх предыдущей версии сохраняет историю, шаблоны и настройки. Пакеты для Windows 10 x64 от 1809/LTSC 2019 и Windows 11 x64 используют общую программу. Проверки текущего рабочего стола не заменяют отдельный прогон на LTSC 2019 и мониторах с разным DPI.
