# Открытые исходники и проверка выпуска

Репозиторий [gromit7/ClipShot](https://github.com/gromit7/ClipShot) публичный. Лицензия MIT разрешает изучать и изменять код. Основной код находится в ClipShot/, тесты — в ClipShot.Checks/, сценарии сборки и установщика — в scripts/ и ClipShot/installer.nsi. Исходные изображения значков находятся в ClipShot/Branding/, повторная подготовка ICO — scripts/Build-Icons.ps1.

## Как связать установщик с исходниками

Каждый выпуск имеет отдельный тег, например v0.6.2. На странице Releases доступны архивы исходников этого тега. Файл ClipShot-0.6.2-buildinfo.json указывает полный идентификатор коммита, версию SDK и SHA-256 установщика, exe и основной сборки. Файл SHA256SUMS.txt содержит контрольную сумму установщика; отдельный файл проверок показывает локальные результаты без личных данных. Номер версии также встроен в exe и показан в окне приложения.

Контрольная сумма подтверждает целостность скачанного файла, но сама по себе не доказывает соответствие бинарного файла исходникам. Для независимой проверки можно собрать приложение из указанного тега. Побайтовая воспроизводимость NSIS/WinUI-пакета пока не заявляется: служебные ресурсы и метки времени могут отличаться. Автоматическая сборка из исходников и отчёты тестов открыты во вкладке [Actions](https://github.com/gromit7/ClipShot/actions).

```powershell
git clone https://github.com/gromit7/ClipShot.git
Set-Location ClipShot
git checkout v0.6.2
./scripts/Setup.ps1
./scripts/Build.ps1 -Test -Publish
./ClipShot-app/ClipShot.exe
```

Скачайте установщик из Releases в эту папку и проверьте его сумму:

```powershell
Get-FileHash ./ClipShot-Setup-0.6.2.exe -Algorithm SHA256
```

Сравните результат с SHA256SUMS.txt из того же выпуска. Для собственной сборки установщика нужен NSIS 3 и команда scripts/Test-Release.ps1 из docs/TESTING.md. Локальные проверки установки используют только синтетические данные и отдельный TESTROOT.

Проверки GitHub не заменяют тестирование мышей, аудиоустройств и нескольких мониторов на реальных ПК. Личная история буфера не публикуется и в тестовые отчёты не включается.
