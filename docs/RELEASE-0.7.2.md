# ClipShot 0.7.2

- Автоматические проверки только по будням в 09:00 и 15:00 по времени ПК. Каждая — один короткий запрос к общей ленте GitHub; без API-цепочек и повторов после перезапуска. Пропущенные проверки не накапливаются.
- Проверка обновления одним нажатием в меню трея. Фоновая загрузка и установка во время перерыва. В главном окне нет номеров версий и сообщений «актуальная версия»; после установки появляется только «Программа обновлена».
- Компактная панель без верхней строки: даты сверху, шаблоны закреплены снизу, пустые разделы скрыты, у поиска только лупа. Щелчок по рабочему столу или другой программе плавно скрывает панель. Настройки и редактор при этом защищены от случайного закрытия. Правый клик на пустом месте открывает настройки и справку. Окно можно перетаскивать за пустое место, менять размер за нижний угол, скрывать и показывать значком трея.
- Подсветка разделов и клипов стала мягче, без резкого сдвига содержимого и перехвата фокуса при наведении.
- «Копировать в буфер» применяет разметку к тому же снимку в истории и к буферу, без создания второго клипа. Имя и признак шаблона сохраняются.
- Экспорт снимков в PNG и JPEG, в том числе из истории. Прозрачность при JPEG заменяется белой подложкой.

Автоустановка остаётся включённой по умолчанию: после пяти минут без ввода, при скрытом окне, без открытого редактора, диалога и захвата. После обновления — только плашка. С 0.7.1 переход выполняется её механизмом обновления; при быстрой ручной проверке всё равно не нужно сохранять настройки. Рабочие горячие клавиши Alt+F2 и Shift+PrintScreen сохранены.
