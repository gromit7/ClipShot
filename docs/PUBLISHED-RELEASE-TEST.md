# Аудит опубликованного выпуска

Задача CS-RELEASE-AUDIT-001. Сценарий проверяет публичные метаданные стабильного выпуска gromit7/ClipShot, не устанавливает и не запускает EXE. Доступ к пользовательским данным и настройкам приложения не нужен. GitHub-аутентификация и приватные конфиги не читаются.

## Запуск

PowerShell 7 рекомендован проектом; сценарий дополнительно проверен в Windows PowerShell 5.1.

```powershell
./scripts/Test-PublishedRelease.ps1 -Tag v0.7.2
./scripts/Test-PublishedRelease.ps1 # latest на момент запроса
./scripts/Test-PublishedRelease.ps1 -SelfTest # полностью без сети
./scripts/Test-PublishedRelease.ps1 -Tag v0.7.2 -MirrorRoot https://example.org/clipshot
./scripts/Test-PublishedRelease.ps1 -Tag v0.7.2 -DownloadInstaller
```

Необработанная ошибка даёт ненулевой код выхода при запуске через powershell/pwsh -File. PASS возвращается объектом; при желании вызывающая сторона может передать его в ConvertTo-Json.

## Проверки

- Опубликованный release не draft/prerelease; строгий тег vX.Y.Z.
- Ровно один setup asset; его имя, размер и digest сопоставляются с buildinfo.
- buildinfo и checks имеют ту же версию и sourceCommit, что коммит тега. Поддерживаются lightweight и до пяти уровней annotated tags.
- Unit passed > 0, failed = 0, total = passed; список локальных проверок непустой и каждый Passed строго true.
- URL метаданных/установщика принадлежит указанному релизу ClipShot на GitHub. Редиректы скачивания GitHub поддерживаются.
- MirrorRoot должен быть HTTPS без пользовательских данных, query/fragment и нестандартного порта. Запрашивается строго ROOT/vX.Y.Z/ClipShot-Setup-X.Y.Z.exe с Range bytes=0-1023. Требуются 206, точные Content-Range, Content-Length и фактические 1024 байта. Редиректы зеркала запрещены. Это намеренно строгая проверка, не общий HTTP-клиент.
- JSON ограничен 1 MiB; размер установщика 1 KiB–250 MiB. Тайм-аут запроса метаданных 30 секунд, зеркала 15 секунд; отдельное ожидание чтения блока тела ограничено 15 секундами. Эти ограничения не задают общий дедлайн всего аудита.

## Полная загрузка

Без -DownloadInstaller установщик не скачивается целиком. Явная опция создаёт новый каталог ClipShot.ReleaseAudit-<GUID> в системной временной папке, открывает файл только через CreateNew и проверяет полный размер и SHA-256. Путь возвращается в DownloadPath. Файл не запускается; при ошибке неполный файл оставляется для диагностики. Автоматического удаления и установки нет. Полная загрузка проверяет GitHub-пакет, а не зеркало.

## Реальные ограничения

PASS метаданных не доказывает исправность установленной программы, состав внутреннего payload установщика, UI, подпись издателя или независимость самих отчётов. Без полной загрузки digest — сравнение опубликованных утверждений; Range-зонд зеркала подтверждает ответ и заявленный размер, но не идентичность целого файла. Компрометация источника метаданных этим аудитом не исключается. Сценарий не проверяет CI, feed/rollback или доступность из всех сетей; анонимный GitHub API может ограничить частоту. Ошибка сети является неуспешным аудитом, а не доказательством повреждения релиза.
