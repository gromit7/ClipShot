# Устройство ClipShot

Читать при изменениях запуска, обновления, интерфейса или формата хранения.

`ClipShot/App.xaml.cs` управляет единственным экземпляром. `MainWindow` разделён на тематические partial-файлы: история, язык, микрофон, разделы и обновления. Старые имена ClipNest в mutex, реестре и папке данных сохраняются для совместимости.

`Store.cs` хранит историю и настройки. Личная база не используется в тестах и не входит в установщик. Изменения схемы должны сохранять возможность запуска двух предыдущих версий: откат программы не откатывает пользовательские данные.

`ClipShot.Updater` — отдельный процесс без повышения прав. Повторно проверяет SHA-256, просит приложение завершиться, сохраняет только файлы из `FileInventory.json`, запускает установщик и ждёт подтверждения запуска. При ошибке восстанавливает программные файлы. Личную базу не открывает. Снимки восстановления сохраняются в каталоге Updates.

`MainWindow.Sections.cs` управляет боковой панелью и обычным раскрытием. `SidePanelPlacement` работает с физическими координатами монитора, Popup — с DIP; преобразование выполняется на границе. Пустые группы не создаются. Поиск раскрывает результаты внутри списка.

`ScreenshotEditor.cs` переводит координаты экрана в координаты исходного изображения. `AnnotationGeometry.AimArrow` фиксирует наконечник в точке назначения, для выравнивания двигает хвост. `AnnotationRenderer` экспортирует разметку, не изменяя исходный клип.

`MicrophoneNotice` рисует общую плашку. `NoticeLifetime` определяет ожидание движения мыши и затухание сообщений установки; сообщения микрофона кратковременны. Core Audio управляет mute, но не определяет, слушает ли микрофон конкретное приложение.

`ClipShot.Checks` проверяет независимую логику, SQLite на синтетических данных, геометрию, хеши и политику обновления. Режимы `--*-self-test` проверяют опубликованное приложение. `Test-Release.ps1` проверяет установку, обновление работающей программы, восстановление и отказ повреждённого установщика в TEMP/ClipShot.Tests. Ни один fallback тестового обновлятора не должен запускать обычный режим с личной базой.

Выпуск: `scripts/Release.ps1 -MakeNsis <путь> -NotesFile <путь>`. Проверяет пакет, публикует исходники и черновик, сверяет хеш GitHub, включает выпуск в ленту и затем заменяет локальный установщик. Ошибка оставляет предыдущий локальный выпуск. Выпущенные теги и файлы не заменяются. Политика отката описана в AUTOUPDATE-PLAN.md.

UpdateIdlePolicy.cs содержит правило пяти минут и проверку срока автоматической команды. GetLastInputInfo читается без записи пользовательского ввода. MainWindow.Dialogs.cs гарантирует снятие модального состояния через finally; Hide закрывает активный ContentDialog. Редактор не держит флаг dialogOpen и сохраняется при новом захвате. Файлы UpdateIdlePolicy.cs связаны также с отдельным обновлятором, чтобы повторная проверка была одинаковой.
