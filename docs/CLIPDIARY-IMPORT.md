# Импорт Clipdiary

## Поведение

При запуске установленная Clipdiary обнаруживается по исполняемому файлу, без открытия истории. Предлагается импорт: история, шаблоны, выбор папки данных, «Позже» и «Больше не предлагать». При нестандартной папке пользователь указывает её сам. Повторно открыть импорт можно через меню правой кнопки.

Исходные SQLite-базы открываются только после явного нажатия «Импортировать», только для чтения. Источник не удаляется и не изменяется. Личные базы не используются разработчиком в тестах.

История сохраняет исходное локальное время `created`, которое Clipdiary записывает через `datetime('now','localtime')`. В ClipShot дата хранится в UTC и показывается в локальном времени. Не используется время переноса. При совпадении содержимого остаётся самая поздняя реальная дата; количество одинаковых клипов не увеличивается. Старый источник не делает недавно скопированный клип старее. Если тот же текст находится и в истории, и в недатированном шаблоне, исходная дата истории имеет приоритет над техническим временем шаблона. У шаблонов Clipdiary даты нет: техническое время добавления назначается при импорте.

Отдельная галочка сохраняет всю импортированную историю бессрочно: это меняет общий срок хранения ClipShot на «бессрочно». Иначе действует выбранный пользователем срок, и старые записи могут быть удалены обычной очисткой. Шаблоны очистка истории не удаляет.

## Сохранность и отзывчивость

Потоковое чтение сначала записывает промежуточную SQLite-базу в отдельный временный каталог. При декодировании рабочая история не блокируется. Затем выполняется одна транзакция слияния. Отмена или ошибка откатывает все новые записи и изменение срока хранения. Временная база убирается после завершения. Действующие имена, форматирование и содержимое клипов не затираются. Шаблонный статус сохраняется, повторный импорт идемпотентен.

Прогресс содержит только количество записей, результат — добавленные, уже существовавшие и пропущенные. Содержимое буфера не выводится в журналы.

## Формат и ограничения

Статически восстановлен формат установленной Clipdiary 5.7: gzip, little-endian version/count, затем ID/длина/UTF-8-имя/байты каждого clipboard-формата. Поддержаны полный Unicode-текст, PNG и обычные DIB/DIBV5 с нормализацией в PNG. Шаблоны type2 — полный текст, type4 — такой же composite. Заголовки и description не подменяют полное содержимое. Неизвестные, зашифрованные, повреждённые форматы и недостоверные даты пропускаются с учётом в результате. Установлены ограничения размера распакованной записи и изображения.

Тестовые payload созданы искусственно по восстановленному формату. Независимая проверка на fixture, сформированном самой Clipdiary в Sandbox/VM с отключённым общим буфером, пока не выполнена. Совместимость со всеми версиями Clipdiary не заявляется. Тесты не запускали Clipdiary на рабочем столе и не читали личные записи.
