# Общая витрина дистрибутивов

`scripts/Release.ps1` вызывает `scripts/Publish-Catalog.ps1` последним, после полного release gate, GitHub CI, официальной публикации, RF/feed и локального установщика. На витрину передаётся только canonical `ClipShot-<версия>.exe`, канал stable. Новую версию ради интеграции витрины не выпускаем.

Перед вызовом центрального Python hook wrapper заново подтверждает non-draft/non-prerelease GitHub release, точное имя/URL/состояние asset, размер и SHA-256 локального EXE, затем полностью читает публичный RF EXE по HTTPS без перенаправлений и сравнивает размер/SHA. Временная копия загрузки не создаётся. Read-lock защищает локальный пакет от изменения до окончания импорта. Внешний hook получает аргументы отдельными значениями, а не исполняемой строкой.

Центральный hook по умолчанию — `D:/Мои документы/codex-projects/data-clouds.ru/scripts/publish-release.py`; интерпретатор `python` из PATH. Для другого рабочего места standalone wrapper принимает `-Hook` и `-Python`. Контракт и деплой каталога принадлежат проекту data-clouds.ru. В этот репозиторий не копируются ключи, доступы или код SSH-деплоя.

## Ошибка и повтор

Отсутствующий hook, отказ публичной проверки или ненулевой код Python завершают wrapper ошибкой. Итоговое сообщение об успехе Release не выводится. Уже опубликованные GitHub/RF/feed/D не откатываются, их байты не перезаписываются. После исправления причины повторять **только Publish-Catalog.ps1** с существующим проверенным файлом и той же версией; весь Release.ps1 повторно не запускать. Идемпотентность и неизменяемость каталога обеспечивает центральный hook.

Пример проверки без вызова hook (включает настоящее чтение метаданных GitHub и полного RF-пакета):

```powershell
& .\scripts\Publish-Catalog.ps1 -Version "0.7.12" -Setup "D:/install/Codex Software/ClipShot/ClipShot-0.7.12.exe" -CheckOnly
```

Для подтверждённой публикации витрины тот же вызов выполняется без `-CheckOnly`; это отдельное production-действие. Клиентские feeds, подписи других проектов и legacy URL не меняются.

## Проверки

`scripts/Test-CatalogPublication.ps1` использует синтетический EXE, фиктивные GitHub/HTTP-ответы и настоящий локальный Python stub без сети/SSH: 11 проверок. Покрыты CheckOnly, draft/beta, неверные digest/URL, неполное или неверное публичное содержимое, HTTP-ошибка, попытка изменения EXE во время проверки, точные аргументы hook и ненулевой exit code. Временные данные принадлежат общему TestWorkspace и очищаются в finally. Этот этап включён в Test-Release.ps1.

30.10.2026 отдельно обнаружено: RF canonical 0.7.12 доступен, DE canonical возвращает 404, DE legacy `ClipShot-Setup-0.7.12.exe` доступен. Wrapper подтверждает RF; устранение DE routing не входит в интеграцию каталога и требует отдельной проверки транспорта. Отсутствие подписи в текущем schema=1 ClipShot feed не следует путать с проверкой SHA пакета.
