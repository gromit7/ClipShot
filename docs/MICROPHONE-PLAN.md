# Управление микрофоном — реализация 0.6.1

Стандартный Core Audio: перечисление активных capture endpoints, GetMute, SetMute и проверка результата. Запись звука не открывается. Названия устройств читаются из их свойств. При запуске звук не меняется.

Основной значок ClipShot в трее меняет цвет фона: зелёный — включён, красный — выключен, жёлтый — смешанное состояние, серый — недоступен. Левое нажатие открывает историю, в меню правой кнопки доступны переключение микрофона и настройки. Дополнительной иконки нет. Короткая плашка 1,9 секунды в стиле комикс + киберпанк не активирует окно и не забирает текстовый фокус. Изменения другими программами видны после очередного опроса, интервал 750 мс. Переход на системные callbacks можно сделать позже, если измерения покажут необходимость.

Ctrl+Alt+M по умолчанию, также доступны Ctrl+Alt+F3 и отключение сочетания. Глобальный перехват мыши устанавливается только после выбора X1 или X2. По умолчанию боковые кнопки сохраняют обычную функцию. Перехватывается только выбранная кнопка; ввод с флагом injected игнорируется. Сам callback лишь ставит задачу UI и не вызывает Core Audio. Клавиатура/мышь не подключаются в изолированных тестовых режимах. Команда ClipShot.exe --toggle-microphone пересылается работающему экземпляру.

MX Vertical: назначить Ctrl+Alt+M на нужную кнопку через Logi Options+ либо выбрать стандартную X1/X2 в ClipShot. Другие мыши: стандартные боковые X1/X2 либо клавиатура/меню трея. Старый проект MicrophoneToggle и настройки Logi Options+ не менялись. Из прежних наработок использованы механизм Core Audio и неактивирующее уведомление.

Выбор: основной вход Windows, все активные входы либо сохранённые идентификаторы выбранных. При смешанном статусе выключает все выбранные, если все выключены — включает. После переключения перечитывает фактическое состояние каждого исходного устройства, отключение во время операции не считается успехом. Недоступный выбранный вход не заменяется произвольно основным.

Статус означает Windows mute, не наличие сигнала, использование приложением или независимый аппаратный выключатель. Постоянная видимость вне скрытой области трея настраивается пользователем Windows. Устройства с отдельным mute внутри приложения не контролируются через системный endpoint.

Проверено: 14 тестов микрофона (13 на имитаторе и один read-only Core Audio), UI-проверки четырёх значков, свёрнутых настроек, отсутствия перехвата в изоляции и плашки без захвата фокуса. Физическое переключение, нестандартная кнопка MX Vertical и мышь второго тестера требуют ручной проверки на устройствах. Реальные микрофоны автоматические тесты не переключают.

Пользователь подтвердил работу включения/выключения на обычной безымянной горизонтальной мыши. Отдельная проверка MX Vertical остаётся зависимой от её назначения кнопки.
