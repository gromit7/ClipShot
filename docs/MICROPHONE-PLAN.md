# Управление микрофоном — согласованный следующий этап

Функция согласована в анкете 25.10.2026, пока не реализована. Требуется поддержка MX Vertical и обычных мышей. Нужны переключение микрофона, постоянное состояние в трее и короткая плашка при нажатии. Устройств может быть несколько.

Найдены исходники прежних MicrophoneToggle и MicrophoneTray из проекта настройки MX Vertical: управление основным входом через Core Audio, проверка фактического GetMute после SetMute, значок в трее; старый индикатор опрашивает состояние каждые 400 мс. Прежний код просмотрен; он не входит в текущий выпуск.

Для новой реализации:

- Управление звуком не привязывать к модели мыши. Универсальная команда, горячая клавиша и доступные боковые кнопки; у MX Vertical дополнительно возможен запуск команды через Logi Options+. Сигнал особой кнопки проверять на устройстве.
- Выбор конкретного входа, основного входа Windows или всех входов. Сохранять идентификаторы выбранных устройств, не переносить идентификаторы одного ПК на другой.
- Постоянные состояния: включено, выключено, недоступно; для группы также смешанное состояние. При групповом переключении: если все выключены — включить, иначе выключить все. Это предложение, отдельного подтверждения поведения ещё не было.
- Следить за изменениями mute и списка устройств через системные уведомления. Отображать фактическое состояние после команды; обрабатывать недоступность, отключение гарнитуры и смену устройства по умолчанию.
- Плашка примерно на 1–2 секунды с названием и результатом. Постоянный значок пользователь закрепляет в видимой части трея Windows.
- Не смешивать системный mute с наличием сигнала или mute внутри конкретной программы. Аппаратный выключатель отображается достоверно только если устройство сообщает его состояние Windows.
- Не подключать запись звука ради индикации mute. Проверку уровня сигнала, если понадобится, делать отдельной функцией.

Будущие тесты: один/несколько/отсутствующий микрофон, смешанное состояние, отключение устройства во время команды, изменение извне, смена основного входа, повторные нажатия, восстановление трея после Explorer. Автотесты логики на имитаторе устройств; реальные мыши и аудиоустройства — отдельная проверка на обоих ПК.
