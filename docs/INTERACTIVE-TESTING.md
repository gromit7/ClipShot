# Проверки без помех владельцу ПК

## Постоянный порядок

Сборка, xUnit, анализ исходников и серверные проверки идут без управления рабочим столом. GitHub Actions подтверждает отдельную сборку того же коммита. Для публикации всё равно нужен полный релизный сценарий с проверкой окон и установщика.

Проверки WinUI могут активировать окна даже при Start-Process -WindowStyle Hidden. Во время работы владельца не запускать их молча. Заранее согласовать короткий интервал; только синтетическая база TEMP/ClipShot.Tests и тестовая установка /TESTROOT. После завершения сообщить, что рабочий стол свободен.

Для постоянной независимой проверки предложены отдельные виртуальные машины Windows 11 и Windows 10 LTSC 2019. Их пока нет в подтверждённой инфраструктуре проекта. Перед созданием выбрать хост, объём памяти/диска, законные образы и место хранения. Не создавать тестовые учётные записи, не менять безопасность и не включать гипервизор без отдельной задачи. ВМ не должна иметь общий пользовательский буфер или доступ к личной базе ClipShot/Clipdiary.

На основном ПК после подготовки ВМ останутся только проверки специфического оборудования: мышь, микрофон, DPI и несколько мониторов. Выполнять их в согласованный момент. Отдельный RDP-вход на этот же ПК не гарантирует независимость и может прервать сеанс владельца.
