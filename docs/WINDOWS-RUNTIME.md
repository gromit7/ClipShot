# Проверка запуска на разных версиях Windows

`scripts/Test-WindowsRuntime.ps1` проверяет **готовую публикацию** ClipShot на том ПК, где запущен сценарий. Установка приложения, .NET SDK и NSIS не нужны: переносится весь каталог `ClipShot-app`, а не один EXE. Достаточно штатного Windows PowerShell 5.1; для полного прогона нужен открытый интерактивный сеанс Windows.

## Запуск

Из корня репозитория:

```powershell
# Проверить ОС и комплектность публикации, не открывая окна приложения.
./scripts/Test-WindowsRuntime.ps1 -CheckOnly

# Полный прогон готовой публикации.
./scripts/Test-WindowsRuntime.ps1 -ReportDirectory ./TestResults/windows-runtime

# Проверить перенесённую папку на другом ПК.
./scripts/Test-WindowsRuntime.ps1 -PublicationPath 'E:/ClipShot-app' -ReportDirectory 'E:/ClipShot-reports' -TimeoutSeconds 90
```

| Параметр | Значение |
|---|---|
| `-PublicationPath` | Каталог готового приложения; по умолчанию `ClipShot-app` в корне репозитория, независимо от текущего рабочего каталога |
| `-ReportDirectory` | Каталог итогового отчёта; по умолчанию `TestResults/WindowsRuntime/yyyyMMdd-HHmmss-GUID` в корне репозитория |
| `-TimeoutSeconds` | Время ожидания одного тестового процесса: 10–600 секунд, по умолчанию 90 |
| `-CheckOnly` | Только проверки ОС, файлов и версии; приложение и UI не запускаются |

Нужна публикация **ClipShot 0.7.4 или новее**. Runner проверяет настоящую сборку Windows, архитектуру ОС, версию и целостность полезной нагрузки по `FileHashes.json`. Минимум — **Windows build 17763, ОС x64**. Запуск x64-приложения в эмуляции на ARM64 не считается проверкой x64 Windows. Ключом или подменой номера сборки эти ограничения не обходятся.

## Что запускается

Полный прогон выполняет 11 отдельных запусков:

- восемь тем через `--smoke-test --theme=<ID>`: `Gradient`, `Transparent`, `White`, `Black`, `Dark`, `Windows98`, `WindowsXP`, `CatPink`;
- поведение интерфейса — `--interaction-self-test`;
- выделение и обработка синтетического снимка — `--capture-self-test`;
- разметка и экспорт — `--editor-self-test`.

Каждый процесс получает собственный `%TEMP%/ClipShot.Tests/<GUID>` через `CLIPSHOT_TEST_ROOT`, заданную только в окружении дочернего процесса. Окружение родительского PowerShell сохраняется без изменений, в том числе при ошибке. Приложение всегда запускается с флагом теста; обычный запуск без флага запрещён. Временная база содержит только синтетические записи.

Runner не запускает установщик, не обновляет рабочий ClipShot и не меняет настройки ОС. Личная база `%LOCALAPPDATA%/ClipNest/clips.db` не читается, не копируется и не входит в отчёт. Итоги сохраняются в `runtime-checks.json` и кратком `runtime-checks.txt`: версия выпуска, сборка/архитектура Windows, результаты и время проверок. Личные пути, имена пользователя/ПК и содержимое буфера исключены.

Нулевой код выхода означает успешное завершение выбранного режима. При `-CheckOnly` статус означает готовность к запуску тестов, а не функциональный PASS. Ненулевой код означает отказ проверки или ошибку; отсутствие отчёта либо тайм-аут нельзя записывать как PASS. Результат относится к конкретным версии приложения, сборке ОС и условиям запуска.

## Матрица реальных прогонов

| Приоритет | Windows | Сборка | Что подтверждает |
|---|---|---|---|
| Основной | Windows 10 Enterprise LTSC 2019 x64 | 17763 | Нижняя граница запуска и работа синтетических UI-сценариев на LTSC |
| Основной | Обычная Windows 10 22H2 x64 | 19045 | Работа на последней обычной версии Windows 10 |
| Основной | Ранняя Windows 11 21H2 x64 | 22000 | Нижняя граница варианта Windows 11 |
| Основной | Текущая Windows 11 x64 на тестовом ПК | Фактическая сборка из отчёта | Работа на актуальном тестовом окружении; конкретный номер сохраняется в отчёте |
| Дополнительный | Windows 10 21H2 / LTSC 2021 x64 | 19044 | Дополнительная ветка Windows 10 |
| Дополнительный | Windows 11 24H2 x64 | 26100 | Дополнительная ветка Windows 11 |

Для каждой строки нужен настоящий прогон на соответствующей ОС или её VM. Изменение номера сборки в синтетическом тесте установщика проверяет выбор пакета, а не совместимость WinUI. Успех на текущей Windows 11 не закрывает строки 17763, 19045 или 22000. До появления отчёта строка остаётся **не проверена**.

Возможность запуска ClipShot и срок обслуживания Windows/.NET/Windows App SDK их производителями учитываются отдельно: runtime PASS не продлевает поддержку производителя и не обещает получение обновлений безопасности.

## Границы результата

Синтетический PASS не подтверждает реальные глобальные Alt+F1/Alt+F2/Shift+PrintScreen, обмен данными с системным буфером других программ, физический микрофон или боковые кнопки мыши. Отдельно проверяются смешанные DPI и несколько мониторов, RDP, HDR, защищённые поверхности, блокировка/сон и восстановление Explorer. Снимок в автоматическом сценарии строится из синтетических пикселей.

Установка, обновление и откат проверяются отдельно через `scripts/Test-Release.ps1`; этот переносимый runner их не заменяет. Общая карта проверок: [TESTING.md](TESTING.md).
