# ClipShot 0.7.3

- Версия видна при наведении на значок трея.
- Ручная проверка закрывает настройки без сохранения несвязанных изменений, скачивает и устанавливает найденное обновление без второго нажатия. Открытый редактор защищён от перезапуска.
- После загрузки можно установить обновление сразу или оставить до перерыва. Автоматические обновления остаются тихими.
- Проверка при запуске; тихая установка и перезапуск в безопасный момент.
- Докачка при обрыве соединения и повторные попытки с переходом между источниками.
- Российское зеркало установщика: приложение сравнивает скорость небольших проб и проверяет итоговые размер и SHA-256 по ленте GitHub.
- Установка проверяет целостность файлов и восстанавливает предыдущую версию при ошибке; занятая DLL больше не должна оставлять смешанный комплект.
- Проверено 300 модульных тестов, семь тем, редактор, захват, установка, обновление и восстановление на синтетических данных.
- Галка «Всегда поверх окон» в контекстном меню окна и трея; выбор сохраняется.

Старые версии обнаруживают этот выпуск своим прежним расписанием. Для немедленной проверки используйте «Проверить обновления». Метаданные обновления пока получаются с GitHub; зеркало обеспечивает дополнительный источник установщика.
