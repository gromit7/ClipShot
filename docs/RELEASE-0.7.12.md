# ClipShot 0.7.12

## Что изменилось

- Захват учитывает масштаб каждого монитора и работает с физическими пикселями, без размытия средствами масштабирования Windows.
- В редакторе появились «Вписать» и «100%»: мелкий текст можно рассматривать в исходном размере, увеличивать через Ctrl + колесо и прокручивать большой снимок.
- Стрелки и рамки сохраняются в исходном разрешении; PNG не теряет мелкие детали вне разметки. Исходный снимок остаётся рядом с отдельной правкой.
- Подписи всех команд редактора постоянно видны. Справка дополнена просмотром в исходном размере.

Ранее уменьшенный снимок восстановить до исходного качества невозможно: для проверки сделайте новый. Обновление сохраняет историю, шаблоны и настройки.
