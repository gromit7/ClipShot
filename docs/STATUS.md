# ClipShot — состояние проекта

Версия исходников: **0.5.1**. Windows 11 x64, C#/.NET 10, WinUI 3, SQLite.

## Реализовано

История текста и картинок без дублей, поиск, группы по датам, шаблоны с редактированием и порядком, предпросмотр, Alt+F1 для истории, Alt+F2 для выделенной области, трей, автозапуск и установщик для текущего пользователя.

Семь тем: Gradient, Transparent, White, Black, Dark, Windows98, WindowsXP. Прозрачная использует DesktopAcrylicBackdrop с системным непрозрачным fallback. Старые настройки Light/Default распознаются.

Приложение, проект, ресурсы и публикация называются ClipShot. Для совместимости с ClipNest сохранены папка пользовательских данных, имя mutex, команды завершения и ключи реестра. Установщик обновляет прежнюю установку и путь автозапуска, убирает прежнее имя exe и создаёт ярлыки ClipShot. Личную базу не переносит и не удаляет.

## Проверки

111 независимых xUnit-тестов проходят, включая палитры и контраст. Автопроверки семи тем и сценарии интерфейса/захвата проходят. Проверка полного пакета 0.5.0 выполняется по docs/TESTING.md; окончательный результат записывается в TestResults/release-checks.json.

Выпуск 0.4.3 ранее прошёл полный прогон: 99 тестов логики, 15 проверок поведения и установку/обновление/удаление в изолированной среде. Личную историю буфера при тестировании не читают и не копируют.

Визуальная проверка 0.5.0 пока ограничена заблокированным сеансом Windows: Computer Use вернул GetCursorPos 0x80070005. После разблокировки проверить фактический вид тем. Сборка не является доказательством визуального качества.

## Команды

- Подготовка: ./scripts/Setup.ps1
- Сборка, тесты, публикация: ./scripts/Build.ps1 -Test -Publish
- Полный выпуск: ./scripts/Test-Release.ps1 -MakeNsis <путь-к-makensis.exe> -PublishInstaller
- Публикация: ClipShot-app/ClipShot.exe
- Установщики на ПК разработчика: D:/install/Codex Software/ClipShot-Setup-<версия>.exe, без подпапок.

Репозиторий: https://github.com/gromit7/ClipShot. Описание поведения и ограничений — README.md. Матрица проверок — docs/TESTING.md.

## Исправление установщика 0.5.1

Пользователь показал испорченный русский приветственный текст в 0.5.0. Причина: UTF-8 без BOM интерпретировался NSIS как ACP. В 0.5.1 добавлены явный /INPUTCHARSET UTF8, UTF-8 BOM исходника и проверка реальных LangString из собранного exe через /LANGCHECK (без установки). Выпуск проверяется. В D:/install/Codex Software держать только актуальный ClipShot-Setup-<версия>.exe; старые архивируются в outputs.
