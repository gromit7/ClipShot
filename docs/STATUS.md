# ClipShot — состояние проекта

Исходники **0.6.0**, Windows 11 x64, C#/.NET 10, WinUI 3, SQLite. Публичный репозиторий https://github.com/gromit7/ClipShot, ветка main.

В 0.6.0 добавлены разметка сохранённых снимков (стрелки с выравниванием, рамки, текст, мозаика, скрытие, undo/redo, копирование и PNG), русский по умолчанию с English в настройках, сохранение открытого окна после выбора клипа, необязательная вставка в предыдущее приложение при наличии текстового курсора. Семь тем и шуточная справка сохранены.

Микрофон: стандартный Core Audio, отдельный значок трея, короткая плашка без перехвата фокуса, Ctrl+Alt+M (в настройках также Ctrl+Alt+F3/нет), опциональные X1/X2, основной/все/выбранные микрофоны. --toggle-microphone передаёт команду существующему экземпляру. Каждые 750 мс перечитывает статус; сам звук при запуске не меняется. При смешанном статусе выключает все выбранные, при выключенном включает. Это mute Windows, не индикатор записи или независимого аппаратного выключателя. Использованы принципы прежнего MicrophoneToggle (Core Audio + неактивирующая плашка); старый проект и Logi Options+ не изменены.

156 xUnit-тестов прошли, включая реальное read-only перечисление микрофонов без переключения звука. Проверки семи тем, поведения окна, отсутствия записи в буфер в изоляции, неактивирующей плашки, четырёх значков микрофона, захвата и редактора прошли. Настройки микрофона визуально проверены на синтетических данных. Полный выпуск 0.6.0 прошёл: проверены пакет, русский текст собранного установщика, изолированная установка, обновление запущенной версии и удаление с сохранением данных. В D:/install/Codex Software только ClipShot-Setup-0.6.0.exe; предыдущий выпуск архивирован в outputs. Результаты: TestResults/release-checks.json.

Личную базу %LOCALAPPDATA%/ClipNest/clips.db не читать и не копировать. Старые пути, mutex и ключи реестра сохранены для совместимости. Перед pull всегда проверять git status; не перезаписывать незакоммиченные изменения. SDK work/dotnet/dotnet.exe, пакеты work/packages, NSIS work/nsis/nsis-3.13/makensis.exe. Сценарий выпуска копирует только проверенный релиз, всегда с версией в имени, без подпапок; старые установки тестировать только /TESTROOT в TEMP/ClipShot.Tests.

Следующие согласованные задачи: OCR, исключения программ, пауза истории, перенос шаблонов, шифрование истории, сочетания отдельных шаблонов, закрепление окна. План: docs/ROADMAP.md. Реальное переключение на MX Vertical/мыши тестера, приложения с нестандартным текстовым курсором, смешанные DPI и физические выключатели требуют ручной проверки. Синхронизация отложена. Постоянная блокировка этого ПК уже отключена ранее; резервная копия/откат outputs/Windows-Autolock, не запускать Restore без просьбы.
