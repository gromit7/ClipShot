# ClipShot — состояние проекта

Исходники **0.6.2**, Windows 11 x64, C#/.NET 10, WinUI 3, SQLite. Публичный репозиторий https://github.com/gromit7/ClipShot, ветка main.

В 0.6.0 добавлены разметка сохранённых снимков (стрелки с выравниванием, рамки, текст, мозаика, скрытие, undo/redo, копирование и PNG), русский по умолчанию с English в настройках, сохранение открытого окна после выбора клипа, необязательная вставка в предыдущее приложение при наличии текстового курсора. Семь тем и шуточная справка сохранены.

Микрофон: стандартный Core Audio, цвет основного значка ClipShot (без второй иконки), короткая плашка в стиле комикс + киберпанк без перехвата фокуса, Ctrl+Alt+M (в настройках также Ctrl+Alt+F3/нет), опциональные X1/X2, основной/все/выбранные микрофоны. --toggle-microphone передаёт команду существующему экземпляру. Каждые 750 мс перечитывает статус; сам звук при запуске не меняется. При смешанном статусе выключает все выбранные, при выключенном включает. Это mute Windows, не индикатор записи или независимого аппаратного выключателя. Использованы принципы прежнего MicrophoneToggle (Core Audio + неактивирующая плашка); старый проект и Logi Options+ не изменены.

161 xUnit-тест прошёл, включая реальное read-only перечисление микрофонов без переключения звука. Проверки семи тем, поведения окна, отсутствия записи в буфер в изоляции, неактивирующей плашки, четырёх цветов общего значка, захвата и редактора прошли. Настройки микрофона визуально проверены на синтетических данных. Полный выпуск 0.6.1 прошёл: проверены пакет, русский текст собранного установщика, изолированная установка, обновление запущенной версии и удаление с сохранением данных. В D:/install/Codex Software только ClipShot-Setup-0.6.1.exe; предыдущий выпуск архивирован в outputs. Результаты: TestResults/release-checks.json.

Личную базу %LOCALAPPDATA%/ClipNest/clips.db не читать и не копировать. Старые пути, mutex и ключи реестра сохранены для совместимости. Перед pull всегда проверять git status; не перезаписывать незакоммиченные изменения. SDK work/dotnet/dotnet.exe, пакеты work/packages, NSIS work/nsis/nsis-3.13/makensis.exe. Сценарий выпуска копирует только проверенный релиз, всегда с версией в имени, без подпапок; старые установки тестировать только /TESTROOT в TEMP/ClipShot.Tests.

Следующие согласованные задачи: OCR, исключения программ, пауза истории, перенос шаблонов, шифрование истории, сочетания отдельных шаблонов, закрепление окна. План: docs/ROADMAP.md. Реальное переключение на MX Vertical/мыши тестера, приложения с нестандартным текстовым курсором, смешанные DPI и физические выключатели требуют ручной проверки. Синхронизация отложена. Постоянная блокировка этого ПК уже отключена ранее; резервная копия/откат outputs/Windows-Autolock, не запускать Restore без просьбы.

0.6.1: плашка визуально проверена на синтетических данных в состояниях «выключен» и «часть включена». Сохраняется белый рисунок буфера, перекрашивается фон исходной иконки; пять новых тестов защищают рисунок, прозрачность и различимость четырёх состояний. Пользователь подтвердил работу управления на обычной безымянной мыши. Полный выпуск 0.6.1 прошёл проверку установки, обновления и удаления с сохранением данных. В D:/install/Codex Software только актуальный ClipShot-Setup-0.6.1.exe.

## 0.6.2 — текущий этап

Подключена именно предоставленная пользователем пара PNG (Branding/MicrophoneOn.png и MicrophoneOff.png), без перерисовки. Многоразмерные ICO 16–256 px генерирует scripts/Build-Icons.ps1. Основной значок, exe, установщик и заголовок окна используют новый рисунок. В трее одна иконка: включённый/выключенный — предоставленные варианты, смешанный — жёлтая отметка, недоступный — серый.

Пустые разделы полностью скрыты; у непустых заголовков фон ClipHeaderBrush, высота 40 DIP, полужирный текст 12 DIP. Визуально проверено синтетическое тёмное окно: новая иконка видна, остались только «Шаблоны» и «Сегодня». 162 xUnit-теста и 34 проверки поведения прошли. Полный установщик 0.6.2 проверен: пакет, русский текст, изолированная установка, обновление запущенного приложения и удаление с сохранением базы и постороннего файла. В D:/install/Codex Software только ClipShot-Setup-0.6.2.exe; прежний выпуск архивирован в outputs.

Открытость: MIT + русское пояснение, CONTRIBUTING.md, русские шаблоны обращений/PR и имена CI-этапов. docs/SOURCE-VERIFICATION.md объясняет теги, сборку, хеши и ограничения; scripts/New-ReleaseEvidence.ps1 создаёт сведения о чистом коммите и отчётах после полного выпуска. Лицензия входит в публикацию и установщик. В настройках ссылка на исходники. CI публикует независимо собранный пакет приложения.

Автообновление пользователь попросил продумать на будущее: docs/AUTOUPDATE-PLAN.md, не реализовано в 0.6.2. Публичный Releases API, фоновые загрузки, подпись манифеста, отложенная установка вне работы с редактором/историей, скрытый перезапуск и откат. Само отсутствие диалогов защиты для неподписанного ПО не обещать. Не запускать новое внедрение автообновления до отдельной реализации и проверок.
