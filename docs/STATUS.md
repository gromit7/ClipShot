# ClipShot — состояние проекта

Исходники **0.7.2**, Windows 11 x64, C#/.NET 10, WinUI 3, SQLite. Публичный репозиторий https://github.com/gromit7/ClipShot, ветка main.

В 0.6.0 добавлены разметка сохранённых снимков (стрелки с выравниванием, рамки, текст, мозаика, скрытие, undo/redo, копирование и PNG), русский по умолчанию с English в настройках, сохранение открытого окна после выбора клипа, необязательная вставка в предыдущее приложение при наличии текстового курсора. Семь тем и шуточная справка сохранены.

Микрофон: стандартный Core Audio, цвет основного значка ClipShot (без второй иконки), короткая плашка в стиле комикс + киберпанк без перехвата фокуса, Ctrl+Alt+M (в настройках также Ctrl+Alt+F3/нет), опциональные X1/X2, основной/все/выбранные микрофоны. --toggle-microphone передаёт команду существующему экземпляру. Каждые 750 мс перечитывает статус; сам звук при запуске не меняется. При смешанном статусе выключает все выбранные, при выключенном включает. Это mute Windows, не индикатор записи или независимого аппаратного выключателя. Использованы принципы прежнего MicrophoneToggle (Core Audio + неактивирующая плашка); старый проект и Logi Options+ не изменены.

161 xUnit-тест прошёл, включая реальное read-only перечисление микрофонов без переключения звука.
