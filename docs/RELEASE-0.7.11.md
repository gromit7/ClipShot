# ClipShot 0.7.11

## Что изменилось

- Изменённый скриншот сохраняется отдельной записью рядом с исходником, а в буфер попадает отредактированный вариант. Исходные пиксели, имя и дата сохраняются. Пара показывается в разделе по последней правке, даже если исходник был снят вчера. Одинаковый результат повторно не дублируется.

- После скрытия и повторного открытия панель компактная: разделы истории, шаблоны и папки свёрнуты. Нужный список раскрывается нажатием. Снимок самой программы сохраняет раскрытое содержимое.
- Папки шаблонов получили отдельный спокойный фон и значок открытой папки. Вложенные записи отличаются отступом и тонкой направляющей.
- Для ручной установки один файл `ClipShot-0.7.11.exe`, подходящий для Windows 10 x64 от 1809/LTSC 2019 и Windows 11 x64. Имена пакетов для старых обновляторов сохранены для совместимости.
- Обновлятор наблюдает новый процесс ещё 10 секунд после подтверждения запуска. Ранний выход считается ошибкой и запускает существующее восстановление. Добавлен ограниченный технический журнал запуска и выхода без содержимого буфера и пользовательских документов.
- Устранена выявленная гонка при переходе со старого обновлятора: дескрипторы родительских процессов удерживаются до проверки кодов выхода. Регрессия специально задерживает ожидание старого процесса и проверяет, что ClipShot продолжает работать после завершения обновлятора.

Обновление устанавливается поверх предыдущей версии и сохраняет историю, шаблоны и настройки. Точная причина отдельного ночного завершения 0.7.10 пока не установлена; усиление проверки запуска не является доказательством устранения всех возможных причин выхода.
