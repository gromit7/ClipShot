# ClipShot — решения и материалы чатов

Сверка 30.10.2026. Это карта источников и актуальных решений, а не новая очередь реализации. Текущее состояние — [STATUS.md](STATUS.md), согласованная очередь — [FEATURE-QUEUE.md](FEATURE-QUEUE.md), продуктовые требования — [requirements.md](../ClipShot/docs/requirements.md).

## Источники

По перечням просмотрены 238 активных и 24 архивных чата Codex, а также 1283 доступных чата ChatGPT (активные и архивные). Это отбор по заголовкам, сводкам и папкам, а не чтение всех сообщений посторонних чатов. В перечне ChatGPT дополнительных совпадений по ClipShot/ClipNest/Clipdiary/буферу обмена не найдено; упоминания внутри чатов с несвязанным названием могут остаться вне такого отбора.

- Чат **Создать сайт дистрибутивов проектов**, ID `01a18b00-17bb-7770-aaa9-534d261d4f7c`: прочитана доступная история; общий каталог приложений и договорённости о публикации ClipShot.

Учётные записи, пароли и посторонние административные материалы сюда не переносятся. Старая недоступность сайта не считается его текущим состоянием.

## Что не потерять при продолжении

1. Официальный выпуск по последним подтверждениям проекта — **0.7.12**. Подготовленная **0.7.13** с сохранением выбора удалённого ярлыка ещё требует полного release gate и публикации. Фоновые проверки не заменяют интерактивные; исторический блокер — Screen-saver, состояние рабочего стола при этой сверке не проверялось.
2. Очистка тестовых данных уже выполнена и подтверждена; не повторять массовую очистку. Диагностика сохранена в `.artifacts/temp-cleanup-20261030/REPORT.md` вне Git; правила в [TEST-DATA-LIFECYCLE.md](TEST-DATA-LIFECYCLE.md).
3. Причина прежнего ночного завершения 0.7.10 не установлена. Успешное наблюдение 0.7.11 закрыло наблюдение, но не доказало причину старого выхода.
4. Отдельный физический прогон LTSC 2019, смешанные DPI и реальные масштабы 125/150/200% не объявлять пройденными по manifest, симуляции или тесту установщика.
5. Каталог data-clouds.ru: тёмный минимальный интерфейс, описания по нажатию, вход по паролю без логина; загрузки программ и feeds остаются без пароля. Секрет входа в проекте не хранить. Post-release hook уже подключён, ошибка каталога не требует перевыпуска приложения; повторять только Publish-Catalog. См. [CATALOG.md](CATALOG.md).
6. DE canonical URL при сверке другого чата 30 октября возвращал 404, совместимый legacy URL работал. Это историческое подтверждение, не новая сетевая проверка. Не менять nginx/сеть в рамках переноса контекста.
7. Есть расхождение локальной выдачи: правила требуют `D:/install/Codex Software/ClipShot-<версия>.exe` без подпапки; при этой сверке найден файл `ClipShot-0.7.12.exe` внутри подпапки ClipShot. Зафиксировать для следующего штатного выпуска; файлы при сборе контекста не перемещались.

## Отложенный согласованный объём

OCR, исключения приложений, пауза записи, резервная копия/перенос шаблонов, шифрование истории и горячие клавиши отдельных шаблонов остаются в [ROADMAP.md](ROADMAP.md). Не активировать их автоматически. Синхронизация пользовательской истории отдельно от Git пока не реализуется; протокол/сервер не согласованы.

## Приоритет новых уточнений

- 18:00 заменяет прежние 17:00 в исторических ответах.
- Один универсальный установщик заменяет прежние два пользовательских пакета.
- Нажатие на заголовок заменяет прежнее автоматическое раскрытие по наведению.
- Лупа без автоматического фокуса заменяет первоначальное «поиск сразу в фокусе».
- Клик по плашке заменяет старое скрытие после движения мыши.
- Нормальная справка заменяет раннюю шуточную инструкцию.

История чата содержит старые разрешения на конкретные административные действия. Они не превращаются в новые задачи ClipShot и не расширяют действующие ограничения. Личные базы ClipShot/Clipdiary, содержимое буфера, снимки и секреты не переносились.
