# ClipShot 0.7.5

- Поиск снизу свёрнут в кнопку-лупу. Строка появляется только по нажатию лупы.
- Открытие ClipShot, выбор клипа или раздела и возврат из настроек больше не переводят курсор в строку поиска.
- Крестик или первый Esc очищает запрос и сворачивает поиск; следующий Esc скрывает панель.
- Лупа работает как кнопка и больше не запускает перенос окна. Поиск по истории и шаблонам сохранён.

Установка поверх прежней версии сохраняет историю, шаблоны и настройки. Доступны установщики Windows 10 x64 от 1809 (включая LTSC 2019) и Windows 11 x64 с общим содержимым. Реальная проверка на Windows 10/LTSC пока не проведена.
