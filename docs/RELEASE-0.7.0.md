# ClipShot 0.7.0

- Разделы истории раскрываются сбоку в сторону свободного места. Обычное раскрытие возвращается в настройках.
- Исправлена точность стрелки: наконечник остаётся в указанной точке. Мозаика и скрытие области всегда видны.
- Справка содержит короткий список возможностей и действующих горячих клавиш, без шуток.
- Обновления с GitHub: ненавязчивое предложение, загрузка по нажатию, проверка SHA-256, скрытая установка и перезапуск.
- Восстановление программных файлов при ошибке; аварийная политика GitHub разрешает возврат явно указанных проблемных версий. По умолчанию неактивна.
- После установки и обновления программа работает в трее. Плашка ждёт движения мыши и плавно исчезает.
- Исходники, автоматические проверки, архитектура и правила выпуска открыты; установщик, GitHub и лента обновления сверяются по хешу.

Переход с 0.6.2 на 0.7.0 нужно выполнить вручную один раз: в старой версии обновлятора нет. Дальнейшие выпуски будут предлагаться самой программой. Пользовательские данные сохраняются. Подписи издателя пока нет. Отдельный тестовый канал и синхронизация данных пока не реализованы.

Дополнительная горячая клавиша снимка области: Shift+PrintScreen, включена по умолчанию и отключается в настройках. Alt+F2 сохраняется.
