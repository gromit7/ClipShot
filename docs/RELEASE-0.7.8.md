# ClipShot 0.7.8

## Что изменилось

- Шаблоны можно перетаскивать для изменения порядка, объединять в именованные папки и переносить между папками.
- Сегодня и Шаблоны раскрываются при наведении и спокойно сворачиваются после ухода мыши из списка и предпросмотра.
- Длинные списки используют доступную высоту монитора, а свёрнутое окно закрепляется справа снизу над панелью задач.
- Сверху добавлен компактный язычок для перетаскивания окна.
- Видимая панель сохраняется при снимке через Alt+F2 или Shift+PrintScreen, даже если фокус оставался в другом приложении.
- Плашка с изменениями последних пяти версий остаётся до щелчка по ней.
- История по умолчанию хранится 30 дней. Сохранённый ранее выбор срока сохраняется; шаблоны не очищаются.

Папки одного уровня: перетаскивание к краю строки меняет порядок, в центр другой записи создаёт папку, на существующую папку добавляет запись в неё. Переименование и разбор папки доступны правой кнопкой; разбор сохраняет клипы.

Обновление устанавливается поверх прежней версии с сохранением истории и настроек. Доступны установщики Windows 10 x64 от 1809/LTSC 2019 и Windows 11 x64. Полноценный запуск на физической LTSC 2019 остаётся отдельной проверкой тестеров.
