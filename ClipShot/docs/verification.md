# Проверка версий 0.1–0.2

Дата: 23 октября 2026 года.

## Подтверждено

- Release-сборка C# / WinUI 3 завершена без ошибок и предупреждений.
- Выполнена самостоятельная публикация Windows x64 с .NET и Windows App Runtime.
- В публикацию добавлен обязательный ClipShot.pri: без него опубликованный exe аварийно завершался, хотя запуск из bin работал. Исправление закреплено в csproj.
- Опубликованный exe прошёл `--smoke-test`: код завершения 0, XamlRoot создан, отображаются 3 тестовые записи (текст, шаблон, PNG).
- Через computer-use проверены окно истории, открытие настроек, поиск «ТЕСТОВАЯ» с совпадением «Тестовая запись ClipShot».
- Отдельно отображены текстовый и графический предпросмотры. Фокус после открытия остаётся в Search; подтверждено UI Automation и FocusManager.
- Все 11 проверок из ClipShot.Checks прошли: дедупликация текста/картинок, подъём повторного текста, очистка с сохранением шаблонов, имя и текст шаблона, настройки, очистка старых записей с сохранением старых шаблонов, повторное открытие базы, сохранение свежих записей, индивидуальное удаление.

## Требует обычного пользовательского запуска

- Захват реального системного буфера и копирование обратно в другие приложения, включая HTML/RTF.
- Глобальная горячая клавиша, конфликты с Clipdiary, меню трея, автозапуск после входа в Windows.
- Поведение наведения и перехода курсора между списком и предпросмотром: отображение панели проверено программным открытием, а полная траектория мыши не проверялась автоматически.
- Несколько мониторов, разные масштабы DPI и большая история.

Проверки использовали отдельную синтетическую базу. Обычный режим с мониторингом личного буфера и изменением автозапуска во время проверки не запускался. Тестовые процессы завершены.

## Версия 0.2 — выделенная область

- Добавлено собственное окно выделения WinUI, затемнение, прямоугольная рамка, размер области, отмена Esc и правой кнопкой.
- Alt+F2 зарегистрирован отдельно от клавиши истории; настройки предлагают Alt+F1…F12 и Ctrl+Alt+F1…F12. Проверяется совпадение двух сочетаний, при занятости клавиш настройки откатываются.
- Добавлен пункт захвата в меню трея. При успешном выделении выбранные пиксели преобразуются в PNG, копируются в системный буфер и добавляются в SQLite. Полный рабочий стол на диск не сохраняется.
- 18 проверок базы и геометрии прошли. Новые проверки: прямое и обратное выделение, обрезка у границ экрана, пустая область, отрицательное начало монитора, правильные пиксели/шаг строк, запрет некорректной области.
- `--capture-self-test` опубликованной сборки: exit 0, выделение 240×160, PNG-декодирование с совпадением размеров, добавление в тестовую историю и отмена.
- Интерактивный тест на синтетическом изображении завершился успешно с областью 520×368; результат подтверждён тестовым отчётом, автоматизация ввода мыши не выполнялась.
- Повторный `--smoke-test` опубликованной сборки: exit 0, XamlRoot=True, 3 записи.
- Реальное чтение рабочего стола через GDI, копирование снимка в системный буфер и глобальный Alt+F2 в пользовательском сеансе ещё не проверялись. Смешанные DPI и несколько мониторов требуют пользовательской проверки. Тестовые режимы не читают рабочий стол и не меняют буфер.

## Версия 0.3

- Исправлен ошибочный Win32-модификатор: использовался MOD_SHIFT=4 вместо MOD_ALT=1. Добавлены две регрессионные проверки; всего 20 проверок базы, геометрии и модификаторов прошли.
- Добавлен собственный ICO в exe, заголовок окна, трей и ярлыки. Shell_NotifyIcon подтвердил добавление значка.
- Реальными нажатиями в --shell-test получены WM_HOTKEY для Alt+F1 и Alt+F2, показано окно выделения. Тестовый отчёт подтвердил получение области 699×385; ввод мыши автоматизацией не подтверждён.
- Повторный запуск открывает существующий экземпляр; --quit завершает его штатно. После перезапуска Explorer значок восстанавливается.
- NSIS-установщик собран без предупреждений, установка завершилась кодом 0. Проверены версия, наличие ICO, ярлыков рабочего стола/Пуска и корректного UninstallString. Пользовательская база не включена в пакет.
- В установленной версии реальный Alt+F2 открыл захват рабочего стола через GDI. Проверка отмены остановлена физическим Esc пользователя; дальнейшая автоматизация прекращена. Реальная передача выделенного изображения в буфер не проверена автоматически.

## Версия 0.3.2

- Удалён крестик, рисовавшийся отдельными XAML-линиями по PointerMoved одновременно с системным курсором. Используется контрастный нативный .cur с центральной горячей точкой. Перемещением курсора управляет Windows.
- PointerMoved только запоминает последнюю область; рамка обновляется через CompositionTarget.Rendering, без очереди перерисовок для каждого события. PointerReleased по-прежнему обрезает по последней точной координате события.
- Собственная проверка требует, чтобы отложенная область успела отрисоваться. Публикация и --capture-self-test прошли: exit 0, PNG 240×160, история и отмена.
- Субъективная плавность на устройстве пользователя не измерялась автоматически.

## Версия 0.4.0 — основное окно

- Добавлены общий заголовок, значок буфера, настройки и системная кнопка закрытия без дублирующего заголовка. Сохранены системное перетаскивание за заголовок и изменение размеров.
- Поиск получил значок и высоту 42 DIP; строки, группы, счётчики, миниатюры, разделители и подсказки клавиш приближены к согласованному макету. Выбор обозначается нейтральной заливкой и полосой слева. Снимки показывают размеры в пикселях.
- Публикация Release успешна. Изолированные проверки Light и Dark: exit 0; XamlRoot=True; Layout=True; CaptionInset=48, SearchWidth=476, SettingsX=408. Кнопка настроек не перекрывает системную кнопку закрытия.
- Данные и настройки обычной базы в ходе тестов не читались и не менялись; использовалась отдельная синтетическая база.
- Визуальный снимок окна получить не удалось: Computer Use вернул GetCursorPos, 0x80070005 (отказано в доступе); процессы LockApp и LogonUI присутствовали. Запрошена разблокировка сеанса. До неё визуальная оценка макета остаётся непроверенной.

После разблокировки пользователя визуальная проверка завершена:

- Светлая и тёмная темы просмотрены на синтетических данных. Общий заголовок, системный крестик, кнопка настроек, поиск, группы и строки не перекрываются.
- Поиск EXAMPLE показал совпадение в шаблоне test@example.com и в адресе https://example.com/project, без учёта регистра.
- У картинки отображаются миниатюра и подпись 320×180 · PNG. Проверен увеличенный предпросмотр тёмной темы; фокус поиска сохраняется.
- Кнопка настроек в новом заголовке открыла диалог; элементы и нижние кнопки помещаются в окно.
- Тестовый процесс завершён. Установленная обычная версия и её база при визуальной проверке не изменялись.
