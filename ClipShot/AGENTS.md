# ClipShot

Windows 11 x64, C#, .NET 10, WinUI 3, SQLite. Русский интерфейс по умолчанию.

- Соблюдать ../AGENTS.md, при продолжении читать ../docs/STATUS.md.
- Сборка из корня репозитория: scripts/Build.ps1 -Test -Publish. Проверка выпуска — ../docs/TESTING.md.
- Установщик: build-installer.ps1 -MakeNsis <абсолютный путь>. Установка для текущего пользователя без повышения прав.
- Синтетические проверки опубликованного exe: --smoke-test, --interaction-self-test, --capture-self-test, --editor-self-test. Для визуальной проверки --demo, --capture-demo, --editor-demo. В тестовых режимах личная база и настоящий буфер не используются.
- Личная база %LOCALAPPDATA%/ClipNest/clips.db содержит потенциально секретные данные. Не читать, не копировать и не включать в отчёты/репозиторий/установщик.
- Тесты хранилища: dotnet test ../ClipShot.Checks -c Release.
- Проверять запуск именно публикации: ClipShot.pri и файлы Assets должны находиться рядом с exe. Успешная компиляция сама по себе не доказывает работоспособность публикации.
- Установщик автоматически тестировать только с /TESTROOT в отдельной папке TEMP/ClipShot.Tests. Не запускать обычную установку на рабочем ПК в качестве теста.
- Значки: исходная пара в Branding/, подготовленные ICO/PNG в Assets/, сценарий ../scripts/Build-Icons.ps1. Предоставленные варианты включённого/выключенного микрофона не перекрашивать; смешанное и недоступное состояния формируются отдельно.
- Исходный код открыт по MIT. Связь релизов с коммитами и контрольные суммы: ../docs/SOURCE-VERIFICATION.md, сценарий ../scripts/New-ReleaseEvidence.ps1. Секреты и личные данные не публиковать.
- Автообновление с 0.7.0: ../docs/AUTOUPDATE-PLAN.md. Архитектура: ../docs/ARCHITECTURE.md. Выпускать через ../scripts/Release.ps1; не заменять опубликованные теги. При изменении базы сохранять совместимость отката на две версии. Синхронизация отложена.
